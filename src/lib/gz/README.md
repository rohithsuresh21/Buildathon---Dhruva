# src/lib/gz

Static place directory built by `data-build/`. About 2,200 ports, airports, ICDs, CFSs and rail yards.

`ports.json`, `airports.json`, `surface.json`, `portnodes.json` hold the rows; `rows-*.ts` are hand-checked additions. Do not edit the JSON by hand: rebuild it from `data-build/` so provenance stays true.
