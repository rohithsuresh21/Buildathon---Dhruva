# src/components

React components. Client components start with `"use client"`.

| File | Purpose |
|---|---|
| `Desk.tsx` | The desk: sentence input, trace, plan, verdict, messages. Holds the shared state |
| `Docket.tsx` | Structured origin, destination and cargo inputs |
| `Safer.tsx` | Finds and compares safer routings |
| `Handover.tsx` | Customer flow: locate, ranked agencies, review, place booking |
| `OrderActions.tsx` | Print, calendar, WhatsApp and copy-link buttons on the slip |
| `ProfileGate.tsx` | Optional first-visit prompt for the sender profile |
| `FlatMap.tsx` | SVG map (natural-earth or mercator) with routes, markers and zones |
| `Landing.tsx` | Landing page |
| `Flap.tsx` | Split-flap style number display |
| `Logo.tsx` | The Dhruva mark and brand lockup |

Subfolders: `globe/` (WebGL globe), `sections/` (landing sections).
